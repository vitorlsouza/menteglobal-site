MENTE GLOBALPUBLISHER

Política de Privacidade

Vigente desde 17 de setembro de 2026

O Mente Global Publisher é uma ferramenta interna da Mente Global. Ela publica os cortes de podcast da Mente Global nas contas que a própria Mente Global administra no YouTube, no Instagram e no TikTok. Esta política descreve exatamente quais dados a ferramenta acessa e o que faz com eles.

Quem usa a ferramenta

Somente a Mente Global. A ferramenta roda no computador do operador, não é oferecida ao público, não tem cadastro de usuários e não coleta dados de terceiros.

Dados acessados em cada plataforma

  • YouTube (Google): permissão youtube.upload, usada para enviar vídeos e definir a miniatura no canal da Mente Global. A ferramenta não lê dados de espectadores, comentários nem estatísticas.
  • Instagram (Meta): permissões instagram_business_basic e instagram_business_content_publish, usadas para publicar Reels na conta da Mente Global e obter o link da publicação.
  • TikTok: permissão video.upload, usada para enviar vídeos como rascunho para a conta da Mente Global.

Onde os dados ficam

Os tokens de acesso às três plataformas ficam guardados no Keychain do macOS, no computador do operador. A Mente Global não mantém servidores próprios e os tokens não são enviados a nenhum serviço além da plataforma a que pertencem.

Com quem os dados são compartilhados

  • YouTube, Instagram e TikTok recebem os vídeos, capas, títulos e legendas que a Mente Global decide publicar.
  • Supabase Storage guarda uma cópia temporária do vídeo e da capa, num repositório privado, apenas pelo tempo necessário para o Instagram buscá-los. A cópia é apagada logo após a publicação, com ou sem sucesso.
  • Telegram recebe avisos operacionais enviados ao próprio operador, como a confirmação de uma publicação.

Nenhum dado é vendido, alugado ou usado para publicidade.

Dados das APIs do Google

O Mente Global Publisher usa os Serviços de API do YouTube.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Ao usar a integração com o YouTube, aplicam-se os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Retenção e revogação

Os tokens são mantidos enquanto a integração estiver ativa. O acesso pode ser revogado a qualquer momento:

  • Google e YouTube: permissões da Conta Google.
  • Instagram e TikTok: nas configurações de apps conectados de cada conta.

Depois de revogado, o token deixa de funcionar e é apagado do computador do operador.

Este site

Este site não usa cookies, não tem ferramentas de análise e não carrega recursos de terceiros. Ele é hospedado pelo GitHub Pages, que registra dados técnicos de acesso conforme a declaração de privacidade do GitHub.
